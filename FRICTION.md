# Friction log

Short notes for the hackathon write-up. Fill these in while you demo. Delete anything that did not actually happen.

## Setup

- What was annoying about installing or running the app locally?
- Did `npm run dev` or `npm run build` fail on the first try? What was the message?

## Alexa+ simulation

- Was it obvious that the tool trail is the agent loop, or did it look like a scripted chat?
- Which utterance did the local planner misunderstand?

## Voice

- Did the browser mic work on the machine you recorded on?
- If you muted spoken replies, why?

## Bedrock / AWS mini challenge

- Did `USE_BEDROCK=true` succeed with the default model id?
- If you had to change `BEDROCK_MODEL_ID` or the region, what did you use?
- Did a model try to skip `policy.check`, and did the host checklist catch it?

## Product

- What would a dispatcher have said that FieldClear could not handle?
- What felt fake, even though the tools really ran?
